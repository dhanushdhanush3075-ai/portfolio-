What I do

Full-stack across AI and product.

From model to interface to search visibility — I work the whole pipeline. Tap any row for detail.

Training and deploying models end-to-end — not just running a notebook once and calling it done.

  • Risk-scoring classifiers built and trained with scikit-learn on real datasets (CICIDS2017)
  • YOLO-based computer vision for object/lesion detection
  • NLP pattern detection across multiple languages and dialects

Real threat-intel plumbing, not a mocked-up dashboard — every check hits a live public feed.

  • VirusTotal, Shodan, Google Safe Browsing, URLScan.io, PhishTank, Hybrid Analysis integrated live
  • Docker-based sandboxed "digital twin" testing so nothing touches the host system
  • Runs on locked-down college/corporate laptops without admin permissions

Backends and interfaces built to actually ship, not just demo on localhost.

  • FastAPI and Flask APIs, including RAG pipelines over real reference data
  • Clean Streamlit interfaces for dashboards and analyst tools
  • SQLite / MySQL / Supabase for data behind the interface

Actively building this out right now — the goal is to take backend and ML work mobile.

  • Android/APK builds, from UI to a shippable package
  • Packaging desktop tools (like AI-DTCTM) as portable installers is the closest step so far
  • Next step: native or cross-platform mobile builds

A model or app is only useful if people can actually find it.

  • On-page SEO: titles, meta descriptions, semantic structure
  • Social preview cards (Open Graph / Twitter cards) so shared links look right
  • Clean site structure that search engines and recruiters can both parse
